# Cinegraphic — Hosted / Guardrail-Friendly Prompt

> **Mode:** Original Reinterpretation  
> **适用：** ChatGPT · Gemini · other hosted image tools with third-party similarity protections

This version does not ask the model to directly reproduce a recognizable third-party poster. It first extracts high-level structure and mood, then rebuilds a new Cinegraphic composition from scratch.

本版本不要求模型直接重制可识别的第三方海报，而是先提取高层构图、情绪与视觉层级，再从零重新设计一张 Cinegraphic 海报。

---

## English

```text
Analyze the provided reference image only for its high-level visual structure.

Extract:
- number of subjects
- emotional relationship between subjects
- dominant mood
- broad pose direction
- camera orientation
- visual hierarchy
- dominant color relationships
- negative-space distribution
- general subject placement

Do not recreate the original artwork.

Create a completely new and original poster inspired only by these high-level characteristics.

If the reference contains recognizable actors, fictional characters, movie posters, brands, logos, iconic costumes, distinctive makeup, proprietary typography, or other protected visual identities, replace them with original equivalents.

Create new:
- faces
- hairstyles
- wardrobe details
- props
- background environment
- typography
- title
- graphic elements

while preserving only the broad emotional relationship, narrative logic and visual hierarchy.

Now reinterpret the scene using the CINEGRAPHIC visual system.

STYLE
Combine:
- mid-century modern editorial poster design
- European graphic illustration
- vintage cinema design
- screen-print aesthetics
- Risograph texture
- 1960s–1970s editorial graphics

CHARACTERS
Use elegant geometric character rendering:
- sharp facial planes
- angular shadows
- simplified anatomy
- elongated proportions
- strong silhouettes
- large flat color fields
- restrained facial detail

Do not attempt to reproduce a real actor or recognizable fictional character.

COLOR
Use a restricted 3–5 color palette.
Preserve only the broad color relationship of the reference, not its exact palette.

Prefer:
- warm cream paper
- deep black or charcoal
- one strong dominant color
- one optional muted accent color

TYPOGRAPHY
Generate new oversized typography as an abstract graphic element.

Typography may appear:
- behind figures
- cropped by the canvas
- partially hidden
- vertically arranged
- overlapping architecture
- extending outside the frame

Do not reproduce the reference image's title, logo, studio credits or distinctive typography.

COMPOSITION
Preserve only the broad visual hierarchy.
Rebuild the layout from scratch.

Use:
- asymmetry
- large negative space
- foreground/background overlap
- simplified architecture
- bold geometric structure

TEXTURE
Add:
- paper grain
- screen-print ink
- Risograph texture
- minor ink misregistration
- subtle wear
- uneven ink density
- restrained halftone texture

FINAL RESULT
The image should feel emotionally related to the reference while remaining visually independent from it.

It should look like an original collectible vintage editorial or cinema poster, not a recreation of an existing poster, campaign or character design.

Avoid:
- exact actor likeness
- recognizable copyrighted character design
- copied movie titles
- copied logos
- copied credits
- iconic costume replication
- exact makeup replication
- exact pose replication
- exact composition replication
- generic AI art
- glossy 3D rendering
- plastic skin
- cluttered backgrounds
- random typography
```

重新设计：

- 发型
- 服装细节
- 道具
- 背景环境
- 字体
- 标题
- 图形元素

只保留原图的大致情绪关系、叙事逻辑和视觉层级。

- 锐利面部切面

- 简化人体结构

- Logo

- 非对称构图
- 大量留白
- 人物与字体前后叠压
- 简化建筑
- 强几何结构

- 杂乱背景
- 随机文字

## Why this version exists / 为什么需要这个版本

Some hosted image tools evaluate the uploaded reference itself, not only the wording of your prompt. In those environments, simply adding phrases such as “make it original” may still fail if the source is a highly recognizable third-party poster.

一些托管图片工具会直接判断你上传的参考图，而不只是判断提示词文字。因此，当参考图本身是高度可识别的第三方电影海报时，仅仅在提示词里写“原创化”依然可能失败。

The reliable workflow is:

`reference → analyze high-level structure → discard protected identity details → rebuild from scratch → apply Cinegraphic`

稳定工作流：

`参考图 → 提取高层结构 → 去掉受保护身份细节 → 从零重构 → 套用 Cinegraphic 视觉系统`
