# Contributing

Suggestions are welcome, but this is not a “submit every Skill” list.

## Suggest a Skill

Open an issue and include:

- Repository URL
- Author / creator
- What the Skill does
- At least one public example image URL
- License or usage restrictions
- A short explanation of what makes its visual system distinct

## Review checklist

A candidate should have a visible, repeatable aesthetic system and real examples. Repositories with no examples, unclear provenance, or near-duplicate visuals may be declined.

## Pull requests

Please edit `data/skills.json` first, then update `README.md` if needed. Run:

```bash
python scripts/validate_catalog.py
```

Do not add third-party example images to this repository unless their license clearly allows redistribution and attribution requirements are satisfied.
