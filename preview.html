HOW TO USE / 3 STEPS

提示词怎么用

01 · 先装 Skill

点击「作者仓库」查看安装方式。提示词里的 $skill-name 只有在 Skill 已加载时才会生效。

02 · 换成你的内容

上传照片、文章或截图；看到 {标题}、{主题}、{颜色} 时直接替换。

03 · 复制直接跑

点「提示词」→「一键复制」，粘贴到 Codex、Claude Code 或其他支持该 Skill 的 Agent 里即可。
